- Algoritmos: São uma sequências de instruções que têm o objetivo de resolver um problema ou realizar uma tarefa específica, são fundamentais na ciência da computação e estão presentes em diversos contextos do dia a dia.
Sua definação - Seria dizer que são uma sequência ordenada de passos na qual resolvem um problema ou executam uma tarefa.
E algumas caracteristicas de algoritmos seriam:
- Sua finitude: Quando o algoritmo termina em um número finito de passos.
- Definição clara: Quando cada passo do algoritmo deve ser bem definido e sem ambiguidade.
- Entradas e Saídas: Quando um algoritmo recebe entradas (dados) e gera saídas (resultados).
- Efetividade: Quando as operações devem ser simples o suficiente para serem executadas de forma prática.
Tambem temos mais de um tipo de algoritmo como:
Algoritmos de Ordenação;
Algoritmos de Busca;
Algoritmos Greedy;
Algoritmos Recursivos. 
Sobre estrutura de dados: São o que os algoritmos frequentemente utilizam para armanezar e organizar dados.
Algumas representações de algoritmos são: 
Pseudocódigo: Descrição em linguagem natural estruturada, mas não executável.
Fluxogramas: Diagramas gráficos que representam os passos do algoritmo.
Linguagens de Programação: Algoritmos que podem ser implementados usando linguagens de programação como Python, C++, Java, etc.
Em resumo, algoritmos são as instruções que orientam como um problema deve ser resolvido, e sua análise e otimização são essenciais para garantir que soluções sejam rápidas e eficientes.

- Tipos primitivos: São os tipos de dados básicos fornecidos pela linguagem de programação, usados para armazenar informações simples. Os principais seriam:
Os inteiros (int): Representando números inteiros, tanto positivos quanto negativos, sem casas decimais.
Ponto flutuante (float ou double): Usados para representar números reais, ou seja, números com casas decimais.
Caractere (char): Representa um único caractere, como letras ou símbolos.
Booleano (bool): Representa valores lógicos, geralmente usados em expressões condicionais. Possui apenas dois valores possíveis: verdadeiro (true) ou falso (false).
String (em algumas linguagens): Embora nem sempre seja considerada um tipo primitivo, em muitas linguagens como Java, a string é um tipo de dado para armazenar sequências de caracteres (ex: "Olá, mundo!").
Tipos nulos (null ou None): Representam a ausência de valor ou a falta de uma referência válida a um objeto.
São tipos fundamentais porque são usados para construir estruturas mais complexas, como arrays, listas ou objetos. Além disso, as operações sobre eles são rápidas e eficientes em termos de memória e processamento.

- Estruturas condicionais: São estruturas de controle de fluxo em programação que permitem executar diferentes blocos de código com base em condições específicas. E temos como principais tipos:
- If (se): A estrutura mais simples na qual verifica uma condição e, se ela for verdadeira, executa um bloco de código.
- Else (senão): Usado junto com o if, define o que será feito caso a condição seja falsa.
- Elif (senão, se): Permite testar múltiplas condições. Se a condição do if for falsa, o elif testa uma nova condição.
- Switch/Case (em algumas linguagens como C, Java, JavaScript): Uma forma alternativa de testar múltiplas condições de forma mais legível, substituindo múltiplos if-elif-else. Verifica uma variável contra vários valores possíveis e executa o código correspondente ao valor encontrado.

Essas estruturas são essenciais para permitir que o programa tome decisões e execute diferentes blocos de código conforme as condições definidas. São usadas em uma ampla variedade de situações, como validação de entrada, controle de fluxo em loops e tomada de decisões em algoritmos.

- Arrays, funções, e objetos:
- Arrays: Estruturas para armazenar múltiplos valores de um mesmo tipo.
Funções: Blocos de código reutilizáveis que realizam uma tarefa específica.
Objetos: Instâncias de classes que encapsulam dados (atributos) e comportamentos (métodos).
